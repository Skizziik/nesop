# ItalianoPerTe: фабрика шортсов

Автоматически делает вертикальные ролики 1080x1920 в формате старых шортсов канала:
цветной фон, жёлтый заголовок, список пар (цифра/местоимение/английское слово + итальянское),
текущая строка подсвечивается зелёным синхронно с озвучкой, последняя строка = `???`
(крючок для комментариев), закладка «сохрани», ведущая в правом нижнем углу.

Озвучка локальная (Piper), монтаж через ffmpeg, всё на CPU, интернет не нужен
(кроме LLM-генерации и заливки, если их включить).

## Запуск

1. Поставь ffmpeg (Windows: `winget install Gyan.FFmpeg`, Mac: `brew install ffmpeg`) и Python 3.10+.
2. Двойной клик `start_windows.bat` (или `./start_mac_linux.sh`).
   Первый раз он сам создаст окружение, поставит зависимости, скачает шрифт и итальянский голос.
3. Откроется браузер: вкладка **Одна кнопка**, выбираешь сколько роликов, жмёшь **СДЕЛАТЬ**.
   Готовые ролики в `output/<дата>_<урок>/video.mp4`, рядом `meta.json` (название, описание, теги, ответ на загадку).

Без интерфейса: `python make.py -n 5`, `python make.py --id colori`, `python make.py --llm "frutta" -n 3`.

## Откуда берётся контент

- `lessons/bank.yaml`: 31 готовый урок (числа, спряжения essere/avere/fare/andare..., артикли, плюралы,
  контрарии, цвета, дни, месяцы, семья, тело, дом, животные, бар). Сделанные помечаются и не повторяются.
- **LLM придумает**: новый урок по теме или на её выбор. Claude API (переменная `ANTHROPIC_API_KEY`)
  или локальная Ollama (`llm.provider: ollama` в `config.yaml`). Сгенерированное сохраняется в
  `lessons/generated.yaml`, его можно поправить руками.
- Вкладка **Свой урок**: пишешь YAML, жмёшь превью/рендер.

## Ведущая (аватар)

По умолчанию выключена. Чтобы вернуть девушку из старых роликов:
экспортируй из HeyGen (или чего ты использовал) зацикленное видео, где она просто стоит/кивает,
**на зелёном фоне**, положи как `assets/avatar/avatar.mp4` и в `config.yaml` поставь `avatar.mode: chromakey`.
Если видео с прозрачностью (`.mov` ProRes 4444 / `.webm`) или просто PNG, ставь `mode: alpha`.
Губы при этом не синхронизируются со словами (это отдельная задача, см. ниже).

## Голос

`tts.engine` в `config.yaml`:
- `piper` (по умолчанию): голос `it_IT-paola-medium`, быстро, на любом CPU. Мужской: поменяй путь на `it_IT-riccardo-x_low.onnx`.
  Скорость: `piper_length_scale` (больше = медленнее).
- `kokoro`: звучит живее (`if_sara` / `im_nicola`), но нужен `pip install kokoro` и установленный в системе espeak-ng.

## Прочее

- Музыка: кинь любые `.mp3` в `assets/music/`, будет подмешиваться тихо (`audio.music_volume`).
- Наклейки: `.png` с прозрачностью в `assets/stickers/` (котики, цветочки), одна случайная на ролик.
- Цвета фона, подсветки, размеры, паузы: всё в `config.yaml`.
- Заливка на YouTube: создай в Google Cloud проект, включи YouTube Data API v3, скачай OAuth client
  (тип Desktop) как `client_secret.json` в корень, поставь `youtube.enabled: true` или галочку в интерфейсе.
  Первый раз откроется логин. Лимит API: около 6 заливок в сутки. `schedule_every_hours: 4` = отложенная публикация раз в 4 часа.
