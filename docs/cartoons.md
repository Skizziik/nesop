# Мультики «Benny & Friends»

Вкладка «Мультики» делает детские мультфильмы на английском (2–5 лет, 16:9, 4–25 минут) от темы до готового пакета для YouTube: mp4, 3 обложки, название, описание с главами и текстами песен, шортсы, сборники.

## Как пользоваться

1. **Мультики → Новый эпизод.** Тема (или пресет), длительность, число историй (1–4), «Сразу отрендерить mp4». Генерация занимает примерно 8–10 минут на минуту мультика (узкое место — озвучка на GPU), рендер — ещё ~1 минуту на 7 минут видео.
2. **Страница эпизода.** Плеер, кнопка рендера, вкладки:
   - «YouTube» — названия, описание, теги, 3 обложки, zip с mp4 + обложками + субтитрами;
   - «Сценарий» — истории и реплики;
   - «Проверка» — темп речи (норма 110–130 слов/мин), средняя длина плана (цель 5–8 с), найденные проблемы и отчёт редактора.
   - Под плеером — контактный лист (кадр каждые 15 с): весь эпизод одним взглядом перед загрузкой.
3. **Шортсы 9:16.** «Сделать 3 шортса»: припев песни, самый смешной момент, вопрос зрителю — пересняты вертикально из тех же сцен (герои крупно), с заголовком-хуком.
4. **Сборники.** В списке эпизодов отметь «в сборник» у 2+ готовых эпизодов → «Собрать сборник»: один длинный ролик с главами по эпизодам и своим YouTube-пакетом.
5. **Каталог ассетов** (кнопка вверху вкладки): все локации, предметы, костюмы, эффекты, действия и герои с превью и статистикой, где что использовалось.

Перед загрузкой: контент помечается «для детей» (made for kids) — без призывов подписаться и комментировать (на детских видео они запрещены и вредят).

## Как устроено

**Конвейер** (`services/api/app/pipeline/cartoon.py`, задача `run_cartoon`):

1. План эпизода (LLM) с учётом истории показа — не повторять идеи, локации и предметы прошлых эпизодов (`cartoon_art.recent_usage`).
2. Сценарий каждой истории (LLM): сцены, биты, мир (время суток/погода), предметы и действия с ними, вопросы зрителю, слово урока.
3. Редактор детского ТВ (LLM): безопасность, длина фраз, слово урока ×5, совпадение цветов/предметов с данными сцены.
4. Арт-директор (LLM, `cartoon_art.py`): визуальный план сцен — время, погода, вставки крупным планом, наезды, переходы; квота разнообразия.
5. Режиссёр (код, `Director`): озвучка голосом каждого героя (Qwen3-TTS + проверка Whisper), расстановка без наложений, камера держит план, паузы на ответ ребёнка 5 с, предметы (дать/бросить/съесть/поднять), костюмы по погоде, заставка/плашки/финал, песни с хореографией.
6. Звук (`music.py`, `sfx.py`): музыка, джинглы, эффекты по событиям анимации, атмосфера по локации и погоде, сведение в −14 LUFS.
7. Автопроверки (`cartoon_art.qa_checks`), отпечаток эпизода для анти-повтора, YouTube-пакет (`youtube.py`, `kids_thumbs.py`), рендер (`project_render.py` → renderer, композиция `Cartoon`).

**Шаблоны** (`packages/templates/src/cartoon`):

- `catalog/` — единый каталог: герои, 16 локаций, 64 предмета с состояниями, костюмы, эффекты, 36 действий, совместимость мира. `npx tsx scripts/export-catalog.ts` пишет `services/api/app/pipeline/cartoon_catalog.json` — Python берёт все списки оттуда (тест падает, если JSON устарел).
- `palette.ts` + `world.tsx` — палитры на токенах и мир: время суток, погода, сезон для любой локации.
- `rig.tsx`, `actions.ts`, `lipsync.ts` — персонажи (профиль при ходьбе, эмоции, моргание, липсинк по фонемам), действия.
- `items.tsx` — предметы с историей (на земле / в руке / в полёте, состояния «надкушено», «лопнул»…).
- `Episode.tsx`, `transitions.tsx`, `overlays.tsx`, `ShowIntro.tsx` — эпизод, переходы, карточки, заставка.
- `Thumb.tsx` — обложки (6 раскладок), `Short.tsx` — вертикальные шортсы.
- `AssetSheet.tsx`, `WorldSheet.tsx` — листы для визуальной проверки: `cd apps/renderer && npx tsx scripts/sheets.ts <папка> locations props states characters faces walk visemes world:<локация>`.

## Добавить ассет

1. Нарисовать (SVG в стиле: контур — `shade(цвет, 0.3–0.35)`, без чистого чёрного и SVG-фильтров, скруглённые формы).
2. Добавить запись в `catalog/index.ts`, выполнить экспорт каталога.
3. Проверить лист (`scripts/sheets.ts`), прогнать `npx vitest run` в `packages/templates` и `pytest` в контейнере api.

Подробности по визуальному разнообразию — `docs/cartoon-visual-variety.md`, исследование про детский контент и YouTube — `docs/research-kids-cartoons.md`.
