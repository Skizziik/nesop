# DECISIONS

Решения, принятые без вопроса владельцу. Формат: что решили → почему.

## Окружение
- **Железо владельца**: NVIDIA RTX 4060, 8 GB VRAM, Windows 11 + Docker Desktop 29 (WSL2). Определено автоматически (`nvidia-smi`), вопрос не задавался. GPU-модели выбираются под 8 GB.
- **Node 22 LTS вместо Node 20** в образах: Node 20 закончил поддержку в апреле 2026, Next 16 требует ≥ 20.9. Remotion 4 поддерживает 22.
- **pnpm через corepack** внутри Docker; локально pnpm не нужен.
- **Python 3.12** для api/worker/tts.

## Архитектура
- **Один образ для api и worker** (`services/api`), разные команды запуска. Очередь — **arq** (async, поверх Redis), т.к. весь api async (FastAPI + SQLAlchemy async + asyncpg).
- **Хранилище — shared volume `/data`**, без MinIO. api раздаёт `/media/*` из `/data`; web проксирует `/api/*` и `/media/*` на api через Next rewrites (один origin, без CORS).
- **Пути ассетов в RenderProps относительные** (`/media/...`). Композиция подставляет `asset_base` (renderer передаёт `http://api:8000`, браузер — пусто). Один и тот же JSON рендерится и в Player, и в renderer.
- **Тайминг**: каждую строку синтезируем отдельно, обрезаем тишину, собираем таймлайн с паузами в worker (numpy), пишем один `voice.wav`. Таймлайн (секунды) кладётся в RenderProps, композиция переводит в кадры. Forced alignment не нужен для list-форматов.
- **Нормализация громкости**: финальный проход в renderer через ffmpeg `loudnorm=I=-14:TP=-1.5:LRA=11` + `-movflags +faststart`, т.к. музыка/SFX микшируются внутри Remotion.
- **cover.png** = `renderStill` кадра 0 (на нём уже весь список — «контракт времени»).
- **JSON Schema — источник правды** в `/schemas`. TS-типы (json-schema-to-typescript) и Pydantic-модели (datamodel-code-generator) генерируются `make codegen` и коммитятся; тест падает, если сгенерированное устарело. Так сборка Docker не зависит от кодогенераторов.
- **Схема БД полная с первой миграции**: таблицы для публикаций, аналитики, A/B, хуков, голосов созданы сразу, фичи за флагами.
- **Шрифты** через `@fontsource/*` (OFL), вшиваются в бандл — рендер работает офлайн.
- **Профили compose**: `COMPOSE_PROFILES=cpu` прописан в `.env.example`, поэтому голое `docker compose up` поднимает CPU-стек. `tts-cpu` и `tts-gpu` — один образ с сетевым алиасом `tts`; gpu-профиль добавляет резервирование NVIDIA. Torch-модели (этап 5) добавят отдельный CUDA-образ.
- **redis-py 5.3.1**, а не 8.x: arq 0.28 требует `redis<6`.
- **Ответ последней строки не произносится**: при `speak: both` голос читает только видимую половину («loro…»), чтобы не выдать ответ.
- **Произношение «andato/a»**: на экране обе формы, голос читает первую («andato»). Правило в `formats/base.py::speech_text`.
- **Голос по умолчанию — `it_IT-serena-medium`**, не `paola` из прототипа: у paola базовая модель lessac с research-only лицензией.
- **Бандл Remotion**: пакет шаблонов лежит вне проекта Remotion, поэтому в webpack добавлен `ProvidePlugin({React})` (иначе «React is not defined» при классическом JSX).
- **Postgres healthcheck по TCP** (`pg_isready -h 127.0.0.1`): во время init временный сервер слушает только сокет, и проверка по сокету проходила слишком рано.
- **Web — Next standalone**, rewrites `/api` и `/media` на `http://api:8000` вычисляются при сборке образа (`API_INTERNAL_URL` build-arg). `compress: false`, чтобы SSE не буферизовался.
- **Индекс похожести пачки**: доля совпадений палитры/раскладки/хука у соседних роликов, 0 — все разные. Показывается в очереди.

## Этапы 4–6 (2026-10-08)
- **Хуки и призывы привязаны к форматам** (`hook_patterns.formats`, список; пусто = любой). «Il 90% sbaglia l'ultima» уместен только там, где последняя строка спрятана; у квиза свои («Scrivi A, B o C»). Формат может дополнительно отсеять неуместный призыв (`cta_fits`): у идиомы без фиксированного ответа не бывает «E cosa si risponde?».
- **Неправильную фразу в «Trova l'errore» голос не читает** — чтобы не закреплять ошибку на слух; голос говорит «Trova l'errore!», а в конце читает исправленный вариант.
- **Скороговорка без forced alignment**: медленная часть синтезируется по словам (каждое слово — отдельный сегмент, точная подсветка), быстрая — целиком. Это точнее и проще, чем выравнивать одну длинную фразу. Aligner (`ctc-forced-aligner` + `wav2vec2-large-xlsr-53-italian`, Apache-2.0) пригодится только для клонированных голосов с паузами внутри фраз; модели и API проверены (docs/research-2026-10.md, scratchpad), в код не включён, пока нет формата, которому он нужен.
- **Фоновая музыка — собственная процедурная генерация** (8 треков, CC0, `pipeline/music.py`): никаких рисков Content ID. Громкость 0.1 от трека с пиком 0.6, финальная нормализация −14 LUFS держит голос на первом плане. Владелец может загрузить свои треки в «Ассетах» — только с указанием лицензии.
- **Тяжёлые TTS-модели в подпроцессах** со своим site-packages (`/models/site/<id>`): у Chatterbox torch==2.6 и numpy<2, у Qwen свежий transformers — в одном процессе несовместимы. Установка из UI = pip + загрузка весов, без терминала. torch ставится из индекса cu126 (GPU) или cpu.
- **Voice design → клон**: Qwen VoiceDesign даёт новый голос на каждый вызов, поэтому по описанию один раз генерируется эталонная фраза, а все строки озвучиваются клоном с неё (0.6B Base). Голос серии стабилен, 1.7B выгружается после создания эталона — укладываемся в 8 GB.
- **Ведущая в нижней полосе кадра** (высота ≤ 330 px, зона подписи YouTube): не перекрывает контент ни одного из 11 форматов. Маскот — своя SVG-пицца, рот по RMS-огибающей голоса (3 состояния), моргание по таймеру; свои PNG-спрайты через путь с `{mouth}`. Видео ведущей на зелёном фоне при загрузке конвертируется в прозрачный webm (VP9 alpha) ffmpeg-ом из Remotion.
- **Lip-sync (MuseTalk) не реализован**: в ТЗ он опционален; в 8 GB вместе с Qwen не помещается одновременно. Режим `lipsync` в схеме есть; готовое видео липсинка подключается как `loop`.
- **Надёжность после перезапуска Docker Desktop**: все контейнеры стартуют одновременно, игнорируя depends_on → воркер ждёт Postgres и при старте возвращает в очередь ролики, зависшие в approved/rendering. Renderer держит один Chromium на все задачи, таймауты 120 с и одна повторная попытка.

## Этап 9 и голос (2026-10-09)
- **Язык контента — итальянский + английский** (решение владельца): аудитория — англоязычные, русского нет ни в роликах, ни в субтитрах, ни в метаданных. Сид-банк переведён, сидер обновляет сид-уроки на месте и удаляет убранные (ложные друзья с испанским убраны). Интерфейс дашборда остаётся русским.
- **Двуязычный преподаватель в лекциях**: доля английского зависит от уровня (A1 ~55%, A2 ~40%, B1 ~15%, B2+ 0%) — новичок должен понимать правило, но больше всего слышит итальянский. Каждая фраза — один язык (`lang`), смешанные фразы режутся, чтобы итальянские слова звучали по-итальянски.
- **Qwen3-TTS 1.7B — основной голос**: на 8 GB держим в VRAM одну модель Qwen (1.7B Base ≈ 4 GB) + Whisper turbo (~1.6 GB). PyTorch 2.14 требует компилятор C для Triton → в образе tts есть gcc.
- **Design-голоса клонируются по x-vector** (не ICL): ICL на 2–4-словных фразах «глотает» слова; замер — 89% против 86% точности.
- **Нет time-stretch для поправок темпа ±10%**: фазовый вокодер librosa давал «металлический» звук и путал распознавание («Ho dormito otto ore» → «Adormito, attore»).
- **Проверка произношения Whisper**: порог 80% совпадения слов, до 3 дублей на фразу, лучший берётся. Ложные срабатывания — английские фразы с итальянскими словами внутри (Whisper в режиме en слышит их по-английски); такие видны в отчёте и не блокируют рендер.
- **Версия движка в ключе кеша TTS** (`cache_tag`): после смены способа синтеза старые дубли не подставляются.
- **Установка тяжёлых моделей — одним вызовом pip**: с `--target` второй вызов не видит уже поставленный torch и ставит его заново (ещё ~6 GB на HDD).
- **Гибридный клон для design-голосов** (2026-10-10): фразы от 6 слов — ICL (манера и интонация одинаковые во всём ролике), короче — x-vector (не «глотает» слова). Только x-vector давал «гуляющую» интонацию — владелец слышал «странные» фразы. Параметры сэмплинга Qwen по умолчанию оставлены: temperature 0.75/0.6 не улучшили разборчивость (99.7% / 98.6% / 99.7% на 24 фразах). Сид детерминированный (текст + номер дубля).
- **Переозвучка фразы в редакторе** — точечное исправление вместо перегенерации лекции: новый дубль (до 3, проверка Whisper) вклеивается в паузу до следующей фразы, громкость подгоняется по старому дублю, ускорение не больше 15%; дорожка голоса пишется новым файлом (версия), старые версии проекта остаются рабочими.
- **Элементы слайда двигаются через `props.layout`** (смещение в долях бокса + масштаб), рамки на превью меряются по DOM плеера — совпадают с рендером без дублирования раскладки.
- **Режим клона по умолчанию — x-vector** (2026-10-10, владелец выбрал на слух по A/B из ICL / x-vector / гибрида). Гибрид и ICL доступны через `QWEN3_CLONE_MODE`.
